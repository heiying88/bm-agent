## 1. 技能安装超限预检 + 失败完整清理（用户原话："学习技能没成功要删干净，免得又出现那个错误"）

背景：fnos 技能 zip 带全平台二进制（darwin 8.7MB 超 8MB 单文件上限、
总量 34.5MB 超 32MB），装进 /data/skills/fnos 后**每次定时任务激活都炸**，
错误注入会话；用户手动删还删不动（容器 root 属主，文件管理器无权限）。

- 限制常量：`crates/infra/bamboo-skills/src/store/mod.rs:82-85`
  （MAX_WORKFLOW_FILE_BYTES 8MB / SKILL 32MB / PUBLICATION 128MB / RETAINED 256MB，
  `SkillSnapshotLimits` struct，Default 硬编码）
- 运行时报错点：store/mod.rs:519-545（激活时逐资源文件检查）
- 激活侧报错入口：`bamboo-engine/src/runtime/runner/session_setup/skill_context.rs:232`
  （"Failed to inspect retained workflow activation"）
- **要做**：a) 装 zip 入口逐文件预检，超限拒绝并点名文件（装包入口在
  plugin_installer.rs 或 agent 的技能保存工具——还没定位到最终点）；
  b) 安装失败回滚：任何原因失败都删掉半成品技能目录；
  c) 或更便宜的替代：激活连续失败 N 次自动隔离（rename 成 .quarantined）
