# Bamboo 项目分析报告（二次开发向）

> 本报告面向准备在本仓库上进行二次开发的工程师，梳理项目定位、架构分层、关键子系统、对外接口与改造切入点。信息基于 2026-10 的代码现状。

## 1. 项目定位

**Bamboo**（crate 名 `bamboo-agent`，命令 `bamboo`）是一个**本地优先（local-first）的 AI Agent 运行时**，用 Rust 编写，定位是"AI 产品的引擎"：

- 桌面产品 **Bodhi**（Tauri 壳）负责界面与生命周期，拉起或复用本地 `bamboo serve`；
- **Lotus Next** 是内嵌的 Web 前端成品包（预构建 zip，源码不在本仓库）；
- Bamboo 本体负责：Agent 循环、19 个内置工具、持久记忆（委托给 `jiandu-memory`）、上下文压缩、Skills、MCP 客户端、工作流与 cron 调度，并通过 HTTP + WebSocket + SSE 对外提供 API；
- 记忆系统遵循 **Jiandu 契约**：Jiandu 拥有权威持久化与词法检索，Bamboo 只负责 prompt 选择与预算，不建第二套持久化/索引层。

数据目录约定：

| 目录 | 内容 |
|---|---|
| `~/.bamboo` | Bamboo 配置、会话、前瞻记录台账（Ledger） |
| `~/.jiandu` | Jiandu 独立数据根（权威记忆存储，默认与 Bamboo 分离） |

`BAMBOO_JIANDU_DATA_DIR` 可为托管主机/验收运行指定隔离的 Jiandu 根目录（仅隔离边界，不是第二种持久化模式）。

## 2. 技术栈

- **Rust** edition 2021，MSRV 1.95，workspace 共 **25 个成员 crate + 根二进制**，约 **35 万行** Rust（含内联测试）。
- 异步运行时 **tokio**（full）；HTTP 服务用 **actix-web 4**（HTTP/1.1 + WebSocket，不是 axum）。
- HTTP 客户端 **reqwest 0.13**；序列化 serde/serde_json/serde_yaml/toml。
- CLI **clap 4**；TUI 用 **ratatui 0.30 + crossterm 0.29 + tui-textarea**。
- 存储：**rusqlite**（bundled SQLite，metrics.db 等）、JSONL 会话文件；加密用 **aes-gcm**。
- 供应链管控：`deny.toml`（cargo-deny）、`.cargo/audit.toml`、`scripts/check-msrv.py`。
- Node 侧资产：`browser-runtime/host.cjs`（playwright 浏览器自动化 sidecar）、`scripts/frontend-package.cjs`（前端包校验打包）。

构建期代码生成（改资源时要注意）：

- `crates/app/bamboo-server/build.rs`：把 `frontend_package/lotus-frontend.zip` 通过 `include_bytes!` 内嵌进服务端，并按 `frontend-manifest.json` 的 **sha256 bundle_hash 校验**；
- `crates/infra/bamboo-skills/build.rs`：按**白名单**（debug、personal-assistant、plan、research、review、simplify、skill-creator）把 `builtin_skills/` 内嵌进二进制——改技能文件无需改构建脚本，但不在白名单里的技能目录默认不会被嵌入。

## 3. 架构分层

Cargo workspace 四层依赖自下而上：`core → infra → engine → app`，根目录 `src/` 是薄 CLI 壳。

```
crates/core     类型与核心抽象（零业务逻辑）
crates/infra    独立基础设施服务
crates/engine   Agent 运行时核心逻辑
crates/app      可执行与入口（server、tui、sdk、broker…）
src/            bamboo 二进制与 CLI 子命令实现
```

### crates/core（约 3.7 万行）

| crate | 职责 |
|---|---|
| `bamboo-domain` | 纯领域类型：session、schedule、workflow、provider_catalog、tool_types、reasoning、ledger 等 |
| `bamboo-agent-core` | 核心抽象：agent、composition、storage、tools、workspace_state，仅依赖 bamboo-domain |

### crates/infra（约 27.6 万行，最大层）

| crate | 职责 |
|---|---|
| `bamboo-config` | 配置与凭据（加密存储、patch、provider_configs、关键词脱敏） |
| `bamboo-llm` | 多 Provider LLM 客户端：providers、router、model_catalog、masking、prompt_ir、retry |
| `bamboo-storage` | 会话持久化：jsonl、search_index、session_inbox、v2/v3 版本化存储 |
| `bamboo-memory` | 记忆门面：memory_store、plan_store、ledger_store、auto_dream、budget（委托 jiandu-memory） |
| `bamboo-compression` | token 预算、摘要器、retrieval_window（上下文压缩） |
| `bamboo-tools` | 19 个内置工具 + registry、executor、permission_override、slash_commands |
| `bamboo-skills` | 技能选择/目录/访问控制，build.rs 白名单内嵌 builtin_skills |
| `bamboo-mcp` | MCP 客户端：manager、protocol、transports、tool_index |
| `bamboo-subagent` | 子代理 fleet/discovery/mailbox/transport |
| `bamboo-permission` | 权限：checker、bash_security、hierarchy、replay |
| `bamboo-plugin` + `bamboo-plugin-protocol` | 插件安装/清单/工具事件协议 |
| `bamboo-a2a` | Agent-to-Agent 协议（card、client、jsonrpc、sse） |
| `bamboo-hooks` | 生命周期钩子分发（命令 + 外部脚本） |
| `bamboo-metrics` | 指标采集（collector、aggregator、bus、worker，SQLite metrics.db） |
| `bamboo-notification`、`bamboo-projects`、`bamboo-infrastructure` | 通知、项目注册表、横切设施 |
| `bamboo-analytics` | dev-only，DuckDB 分析工具（在 members 中但不在 default-members） |

### crates/engine（约 19 万行）

| crate | 职责 |
|---|---|
| `bamboo-engine` | Agent 运行时主体：runtime、execution、agent、session_*、auto_dream、gardener、workflow_run、stream、managers（约 40 个模块） |
| `bamboo-tools`（归 engine 层） | 工具注册与执行 |

### crates/app（约 10 万行）

| crate | 职责 |
|---|---|
| `bamboo-server` | **实际在线服务**：Actix HTTP + WS + SSE、路由、handlers、connect 平台（含飞书适配器 `src/connect/platforms/feishu/`） |
| `bamboo-server-tools` | 服务端工具面：sub_agent、deploy_agent、memory、ledger、session_inspector 等 |
| `bamboo-tui` | 终端 UI 客户端（纯 HTTP 客户端，可自动拉起本地 serve） |
| `bamboo-client-core` | 客户端共享逻辑（chat/execute 请求与事件类型） |
| `bamboo-sdk` | 嵌入式 SDK（agent 模块） |
| `bamboo-broker` | 独立子代理消息总线（WebSocket mailbox 总线、deploy、russh、peer_auth） |

### 根 src/（约 2.4 万行）

- `bin/bamboo.rs`：clap 主入口，定义全部子命令；
- `headless.rs`：`bamboo -p` 无头单次运行（支持 `--stream-json` NDJSON 输出）；
- `actor_cli.rs` / `broker_agent.rs` / `subagent_worker.rs`：子代理 actor 链路；
- `admin_cli.rs` / `read_cli.rs` / `setup_cli.rs` / `plugin_cli.rs`：各子命令实现；
- `claude_code_executor.rs`、`codex_cli_executor.rs`、`codex_app_server_executor.rs`：外部编码代理执行器（详见 `docs/claude-code-executor.md`、`docs/codex-executor.md`）。

## 4. 对外接口

### CLI 子命令

`serve`、`tui`、`init`、`doctor`、`config`、`completions`、`actor`、`broker`、`broker-agent`、`health`、`status`、`sessions`、`stop`、`respond`、`session`、`history`、`schedules`、`skills`、`mcp`（list/status/connect/disconnect/refresh/tools/add/remove）、`plugin`，另有隐藏命令 `subagent-worker`、`codex-provider-token`，顶层 `-p/--prompt` 无头模式。

### HTTP API（默认端口 9562）

- 路由定义集中在 `crates/app/bamboo-server/src/routes/`（`agent.rs`、`bamboo_v1.rs`、`provider.rs`），handlers 在 `src/handlers/`；
- `/api/v1/*`：sessions、stop、respond、history、schedules、skills、mcp、plugins、metrics、workspace、projects、credentials 等约 80+ 条；
- `/healthz`、`/readyz`、`/metrics/v2/*`；
- **v2 传输**：统一多路复用 WebSocket `GET /v2/stream`（设计见 `docs/design/api-v2-transport.md`），配 `/v2/pair`、`/v2/devices` 设备配对；旧版 SSE 为回退路径；
- **LLM 兼容端点**：`/openai/v1/chat/completions`、`/openai/v1/responses`、`/chat/completions`、`/messages`（Anthropic 风格）、Gemini 兼容端点；
- **内嵌前端**：`lotus-frontend.zip` 解包为 `frontend/` 静态目录随服务提供（SPA fallback）。

## 5. 前端与界面体系（中文化现状）

本仓库有**三种界面**，语言现状各不相同：

### 5.1 Web 前端（Lotus Next，内嵌 zip）

- 位置：`crates/app/bamboo-server/frontend_package/lotus-frontend.zip`（3.66 MB 预构建产物，源码在 Lotus Next 仓库）；
- **已内置完整简体中文语言包**（`assets/zh-CN-*.js`），支持 en-US / zh-CN / zh-TW / fr-FR / ja-JP / hi-IN；
- **语言选择逻辑**（从 bundle 反解）：优先读 `localStorage['lotus_ui_locale_v1']`，否则按浏览器语言自动匹配（`zh` 前缀 → 简体/繁体），默认 en-US；设置页有语言切换器；
- 因此**中文浏览器打开即为中文界面，无需改动**；
- ⚠️ 若要改动 Web 前端本身：zip 的 sha256 被记录在 `frontend-manifest.json` 并在构建时校验，正确路径是修改 Lotus Next 源码后经 `scripts/frontend-package.cjs stage` 重新打包，**不要手改 zip**。

### 5.2 skill-creator 的两个 HTML 工具页（本仓库有源码）

- `builtin_skills/skill-creator/assets/eval_review.html`：评估集审核表单页；
- `builtin_skills/skill-creator/eval-viewer/viewer.html`：评估结果查看器（Outputs/基准测试双视图）；
- **已完成中文化**：界面文案、按钮、JS 提示、代码注释均为中文；去掉了 Google Fonts 依赖（国内访问不畅），改用本地中文字体栈；`with_skill/without_skill` 等配置标签映射为中文；
- 占位符契约保持不变：`__SKILL_NAME_PLACEHOLDER__`、`__SKILL_DESCRIPTION_PLACEHOLDER__`、`__EVAL_DATA_PLACEHOLDER__`、`/*__EMBEDDED_DATA__*/`（由 SKILL.md 工作流和 `generate_review.py` 依赖），导出文件名 `eval_set.json`、`feedback.json` 未动。

### 5.3 TUI / CLI（bamboo-tui、clap 帮助）

- TUI（`crates/app/bamboo-tui/src/ui/` 约 15 个界面文件）与 CLI 帮助文本目前**全部为英文硬编码，无 i18n 层**；
- 中文化 TUI 需逐文件替换字符串，注意大量 `#[cfg(test)]` 测试断言了界面文本（如 `app.rs` 的宽度测试），改动需同步改测试；
- 键位参考：`docs/tui-keybindings.md`。

## 6. 测试布局

- 根 `tests/`：38 个集成测试文件（约 2.5 万行），`tests/e2e/` 按 API 域分 27 个子目录，共享 `tests/common/mod.rs` 与 `tests/fixtures/`；
- 11 个 crate 有自己的 `tests/` 目录；
- 大量内联 `#[cfg(test)]`（TUI 的 `ui/chat.rs`、`app.rs` 一半以上行数是测试）；
- 3 个手工 e2e（`e2e_claude_code_manual.rs` 等需真实凭据，默认跳过）。

## 7. 二次开发常见切入点

| 需求 | 入口 |
|---|---|
| 新增 CLI 子命令 | `src/bin/bamboo.rs` 的 `Commands` 枚举 + `src/` 对应 `*_cli.rs` |
| 新增 HTTP 路由 | `crates/app/bamboo-server/src/routes/agent.rs` 注册 + `src/handlers/` 实现 |
| 新增内置工具 | `crates/engine/bamboo-tools/`（registry + executor），权限走 `bamboo-permission` |
| 新增 LLM Provider | `crates/infra/bamboo-llm/src/providers/` + router；设计文档见 `docs/design/multi-provider-routing-refactor-plan.md`、`provider-model-first-class-plan.md` |
| 新增/修改技能 | `builtin_skills/<name>/SKILL.md`；要默认内嵌需加进 `crates/infra/bamboo-skills/build.rs` 白名单 |
| 改上下文压缩策略 | `crates/infra/bamboo-compression/`（token 预算、retrieval_window） |
| 改记忆行为 | 只动 `crates/infra/bamboo-memory/` 门面层（选择与预算），权威存储在 jiandu-memory，**不要**在 Bamboo 里加第二套持久化 |
| 子代理/远程 actor | `bamboo-subagent`、`bamboo-broker`，设计见 `docs/design/subagent-actor-runtime-design.md` 等 |
| 连接外部平台 | `bamboo-server/src/connect/platforms/`（已有飞书适配器可作参考） |

## 8. 构建与运行速查

```bash
# 启动服务（默认端口 9562，自动提供内嵌 Web 前端）
cargo run -p bamboo-agent -- serve

# 启动 TUI（纯客户端，会自动拉起本地 serve）
cargo run -p bamboo-tui

# 无头单次运行
cargo run -p bamboo-agent -- -p "你的指令"

# 供应链/质量检查
cargo deny check
node scripts/frontend-package.cjs stage   # 仅在替换了 Lotus 构建产物后需要
```
